# Community Web Portal
A full-stack community portal built with Node.js, Express, and EJS for sharing local news, events, and handling user messages. Additionally, A fast, interactive full-stack web application built for local communities to share news, post upcoming events, and connect with administrators.

## Features & Architecture

* **Backend Routing:** Built using **Node.js** and **Express.js** to handle HTTP requests, server logic, and user form messages.
* **Server-Side Rendering:** Uses **EJS (Embedded JavaScript)** templates to render dynamic web pages seamlessly.
* **Clean UI Design:** Styled with custom **CSS** to provide a welcoming and responsive interface for news and contact options.
